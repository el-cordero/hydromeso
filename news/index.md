# Changelog

## hydromeso 0.1.0

- Initial package release.
- Replaced synthetic raster examples with a compact sample derived from
  the Cordero-Harris HEC-RAS depth and velocity data for the Big
  Blue-Kansas Rivers confluence.
- Added the exact eight-class Cordero-Harris default scheme and
  validated custom rectangular schemes.
- Added classification for numeric, tabular, vector, raster, and
  scenario inputs.
- Added summaries, scenario comparison, plotting, unit conversion, and
  GIS/table export.
